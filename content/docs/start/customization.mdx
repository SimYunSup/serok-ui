Serok UI는 복사-붙여넣기 방식으로 컴포넌트를 설치하기 때문에, CSS를 통해 완전한 커스터마이징이 가능합니다. 이 가이드는 Serok UI의 스타일링 원칙과 실제 커스터마이징 방법을 설명합니다.

## 기본 원칙

### 1. React Spectrum 변수를 우선 사용하세요

Serok UI는 React Spectrum 기반이므로, **React Spectrum의 CSS 변수**를 먼저 사용하는 것이 가장 좋습니다.

```css
/* ✅ 좋은 예: React Spectrum 변수 사용 */
.my-custom-button {
  background: var(--spectrum-accent-background-color-default);
  color: var(--spectrum-white);
}

.my-custom-button:hover {
  background: var(--spectrum-accent-background-color-hover);
}
```

```css
/* ❌ 나쁜 예: 하드코딩된 색상 */
.my-custom-button {
  background: #6366f1;
  color: #ffffff;
}
```

### 2. Provider 색상은 fallback으로만 사용하세요

React Spectrum이 제공하지 않는 색상이 필요할 때만 Provider 색상(`--serok-*`)을 사용하세요.

```css
/* React Spectrum이 제공하지 않는 연한 보라색 배경이 필요한 경우 */
.custom-notification {
  background: var(--serok-purple-100);
  border: 1px solid var(--serok-purple-300);
}
```

### 3. 단순하게 유지하세요

복잡한 CSS 변수를 만들기보다, 기존 변수를 활용하세요.

## React Spectrum CSS 변수

React Spectrum은 테마와 상태에 따라 자동으로 변경되는 시맨틱 변수를 제공합니다.

### 주요 Accent 변수

```css
/* Accent 색상 (Primary 액션, 선택된 상태) */
--spectrum-accent-content-color-default      /* 기본 상태 */
--spectrum-accent-content-color-hover        /* 호버 상태 */
--spectrum-accent-content-color-down         /* 클릭 상태 */
--spectrum-accent-content-color-key-focus    /* 포커스 상태 */

--spectrum-accent-background-color-default   /* 배경 기본 */
--spectrum-accent-background-color-hover     /* 배경 호버 */
```

### Gray 스케일

```css
/* Gray 색상 (중성 요소) */
--spectrum-gray-50    /* 매우 밝음 */
--spectrum-gray-100
--spectrum-gray-200
...
--spectrum-gray-900   /* 매우 어두움 */
```

### 상태별 색상

```css
/* 상태 색상 */
--spectrum-negative-color-*     /* 에러 */
--spectrum-positive-color-*     /* 성공 */
--spectrum-informative-color-*  /* 정보 */
--spectrum-notice-color-*       /* 경고 */
```

## 커스터마이징 방법

### 방법 1: className 사용 (권장)

가장 직관적인 방법입니다. 컴포넌트에 `className`을 추가하고 CSS 파일에서 스타일을 정의하세요.

```tsx
import { Button } from '@/components/ui/Button';
import './custom-button.css';

export function MyComponent() {
  return (
    <Button variant="primary" className="custom-primary">
      커스텀 버튼
    </Button>
  );
}
```

```css
/* custom-button.css */
.custom-primary {
  background: var(--spectrum-accent-background-color-default);
  padding: 1rem 2rem;
  border-radius: 8px;
  font-weight: 600;
}

.custom-primary:hover {
  background: var(--spectrum-accent-background-color-hover);
}
```

### 방법 2: 인라인 스타일

간단한 변경은 `style` 속성으로 할 수 있습니다.

```tsx
import { Button } from '@/components/ui/Button';

export function MyComponent() {
  return (
    <Button
      variant="primary"
      style={{
        padding: '1rem 2rem',
        borderRadius: '8px',
      }}
    >
      커스텀 버튼
    </Button>
  );
}
```

### 방법 3: 전역 CSS 오버라이드

프로젝트 전체에 적용할 스타일은 전역 CSS 파일에 작성하세요.

```css
/* global.css */

/* 모든 Serok 버튼의 기본 스타일 변경 */
.serok-button {
  border-radius: 0.5rem;
}

/* Primary 버튼만 변경 */
.serok-button[data-variant="primary"] {
  background: var(--spectrum-accent-background-color-default);
}
```

## 실전 예제

### 예제 1: 버튼 색상 커스터마이징

**요구사항**: 회사 브랜드 색상으로 Primary 버튼 변경

```css
/* custom-theme.css */
.serok-button[data-variant="primary"] {
  /* React Spectrum 변수를 오버라이드 */
  --spectrum-button-color: #e91e63;
  --spectrum-button-color-hover: #c2185b;
  --spectrum-button-color-down: #ad1457;
  --spectrum-content-color-default: white;
  --spectrum-content-color-hover: white;
}
```

```tsx
import { Button } from '@/components/ui/Button';
import './custom-theme.css';

export function BrandedButton() {
  return (
    <Button variant="primary">
      브랜드 버튼
    </Button>
  );
}
```

### 예제 2: Tabs 선택 색상 변경

**요구사항**: 선택된 탭을 녹색으로 표시

```css
/* custom-tabs.css */
.serok-tabs {
  /* 선택 표시 색상 변경 */
  --spectrum-tabs-selection-indicator-color: #10b981;
}

.serok-tabs [role="tab"]:hover {
  background-color: #d1fae5;  /* 연한 녹색 */
  color: #059669;
}

.serok-tabs [aria-selected="true"] {
  color: #10b981;
}
```

```tsx
import { Tabs, TabList, TabPanels, TabItem } from '@/components/ui/Tabs';
import './custom-tabs.css';

export function GreenTabs() {
  return (
    <Tabs>
      <TabList>
        <TabItem key="tab1">탭 1</TabItem>
        <TabItem key="tab2">탭 2</TabItem>
      </TabList>
      <TabPanels>
        <TabItem key="tab1">콘텐츠 1</TabItem>
        <TabItem key="tab2">콘텐츠 2</TabItem>
      </TabPanels>
    </Tabs>
  );
}
```

### 예제 3: 다크모드 지원

**요구사항**: 다크모드에서 다른 색상 사용

```css
/* dark-theme.css */

/* 라이트 모드 */
.serok-button[data-variant="primary"] {
  background: var(--spectrum-accent-background-color-default);
  color: white;
}

/* 다크 모드 */
@media (prefers-color-scheme: dark) {
  .serok-button[data-variant="primary"] {
    background: #0ea5e9;
    color: white;
  }

  .serok-button[data-variant="secondary"] {
    background: #475569;
    color: #e2e8f0;
  }
}
```

또는 클래스 기반 다크모드:

```css
/* dark-theme.css */
.dark .serok-button[data-variant="primary"] {
  background: #0ea5e9;
  color: white;
}

.dark .serok-button[data-variant="secondary"] {
  background: #475569;
  color: #e2e8f0;
}
```

### 예제 4: 버튼 크기 완전히 커스터마이징

## Provider 색상 사용

Provider 색상은 React Spectrum이 제공하지 않는 경우에만 사용하세요.

### 사용 가능한 색상

```css
/* Purple 계열 (Accent) */
--serok-purple-100 through --serok-purple-1400

/* Gray 계열 (Neutral) */
--serok-gray-100 through --serok-gray-1400

/* Red 계열 (Error) */
--serok-red-100 through --serok-red-1400

/* Green 계열 (Success) */
--serok-green-100 through --serok-green-1400

/* Blue 계열 (Info) */
--serok-blue-100 through --serok-blue-1400

/* Yellow 계열 (Warning) */
--serok-yellow-100 through --serok-yellow-1400
```

### 색상 단계별 용도

| 범위 | 용도 | 예시 |
|------|------|------|
| 100-300 | 연한 배경 | 알림, 배지, 하이라이트 |
| 400-600 | 중간 톤 | 보조 텍스트, 테두리 |
| 700-900 | 어두운 톤 | 버튼, 주요 텍스트 |
| 1000-1400 | 고대비 | 고대비 모드용 |

### Provider 색상 사용 예제

```css
/* 커스텀 알림 컴포넌트 */
.custom-notification {
  background: var(--serok-blue-100);
  border-left: 4px solid var(--serok-blue-700);
  padding: 1rem;
  border-radius: 0.5rem;
}

.custom-notification-text {
  color: var(--serok-blue-900);
}
```

## 일반적인 실수와 해결법

### ❌ 실수 1: Spectrum 변수가 있는데 Provider 색상 사용

```css
/* ❌ 나쁜 예 */
.serok-button {
  background: var(--serok-purple-700);
  color: var(--serok-gray-0);
}

.serok-button:hover {
  background: var(--serok-purple-800);
}
```

**해결:**
```css
/* ✅ 좋은 예 */
.serok-button {
  background: var(--spectrum-accent-background-color-default);
  color: var(--spectrum-white);
}

.serok-button:hover {
  background: var(--spectrum-accent-background-color-hover);
}
```

### ❌ 실수 2: 색상 하드코딩

```css
/* ❌ 나쁜 예 */
.custom-element {
  color: #6c757d;
  background: #ffffff;
}
```

**해결:**
```css
/* ✅ 좋은 예 */
.custom-element {
  color: var(--spectrum-gray-700);
  background: var(--spectrum-white);
}
```

### ❌ 실수 3: 전역 스타일 충돌

```css
/* ❌ 나쁜 예: 모든 버튼에 영향 */
[role="tab"] {
  color: purple;
}
```

**해결:**
```css
/* ✅ 좋은 예: Serok 컴포넌트에만 적용 */
.serok-tabs [role="tab"] {
  color: var(--spectrum-accent-content-color-default);
}
```

### ❌ 실수 4: 불필요한 CSS 변수 생성

```css
/* ❌ 나쁜 예: 이미 있는 변수를 재정의 */
.serok-tabs {
  --my-tabs-color-default: var(--spectrum-gray-700);
  --my-tabs-color-hover: var(--spectrum-accent-content-color-hover);
}

.serok-tabs [role="tab"] {
  color: var(--my-tabs-color-default);
}
```

**해결:**
```css
/* ✅ 좋은 예: Spectrum 변수 직접 사용 */
.serok-tabs [role="tab"] {
  color: var(--spectrum-gray-700);
}

.serok-tabs [role="tab"]:hover {
  color: var(--spectrum-accent-content-color-hover);
}
```

## 접근성 고려사항

### 색상 대비 확인

커스텀 색상을 사용할 때는 충분한 대비를 확보하세요.

- **본문 텍스트**: 최소 4.5:1 대비율 (WCAG AA)
- **큰 텍스트**: 최소 3:1 대비율
- **UI 컴포넌트**: 최소 3:1 대비율

```css
/* ✅ 좋은 예: 충분한 대비 */
.dark-background {
  background: #1a1a1a;
  color: #ffffff;  /* 대비율 약 15:1 */
}

/* ❌ 나쁜 예: 불충분한 대비 */
.light-background {
  background: #f0f0f0;
  color: #d0d0d0;  /* 대비율 약 1.5:1 - 불충분 */
}
```

### 포커스 표시 유지

키보드 사용자를 위해 포커스 표시를 제거하지 마세요.

```css
/* ❌ 나쁜 예 */
.serok-button:focus {
  outline: none;  /* 접근성 문제 */
}

/* ✅ 좋은 예 */
.serok-button:focus-visible {
  outline: 2px solid var(--spectrum-accent-content-color-key-focus);
  outline-offset: 2px;
}
```

## 디버깅 팁

### 1. 브라우저 개발자 도구 활용

브라우저 DevTools를 열고 Elements 탭에서 컴포넌트를 선택하면 사용 가능한 모든 `--spectrum-*` 변수를 볼 수 있습니다.

### 2. 현재 적용된 스타일 확인

```css
/* 디버깅용 임시 스타일 */
.serok-button {
  outline: 2px solid red !important;  /* 요소 위치 확인 */
}
```

### 3. CSS 변수 값 확인

```tsx
// 개발자 콘솔에서 실행
const element = document.querySelector('.serok-button');
const styles = getComputedStyle(element);
console.log(styles.getPropertyValue('--spectrum-accent-background-color-default'));
```

## 요약

1. **React Spectrum 변수 우선** - `--spectrum-*` 변수를 먼저 사용
2. **Provider 색상은 fallback** - Spectrum이 없을 때만 `--serok-*` 사용
3. **className 활용** - 컴포넌트별 스타일링에 className 사용
4. **접근성 유지** - 색상 대비와 포커스 표시 확인
5. **단순하게 유지** - 불필요한 CSS 변수 생성 지양

이제 Serok UI 컴포넌트를 프로젝트에 맞게 자유롭게 커스터마이징할 수 있습니다! 🎨
