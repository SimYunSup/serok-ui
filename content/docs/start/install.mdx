# Serok UI 시작하기

Serok UI는 Adobe React Spectrum을 기반으로 구축된 고급 컴포넌트 라이브러리입니다. 프로젝트에 컴포넌트를 추가하려면 아래 단계를 따라주세요.

## 개요

Serok UI는 Adobe React Spectrum을 기반으로 구축된 접근성 중심의 컴포넌트 라이브러리입니다. 프로덕션 환경에서 바로 사용할 수 있는 고품질 UI 컴포넌트를 제공합니다.

---

## 1단계: 설정 파일 생성

프로젝트 루트에 `components.json` 파일을 생성하고, CSS 파일 경로를 전역 CSS 파일 위치에 맞게 수정하세요.

```json
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "",
  "rsc": false,
  "tsx": true,
  "tailwind": {
    "config": "",
    "css": "{전역 CSS 파일 경로}",
    "baseColor": "stone",
    "cssVariables": true,
    "prefix": ""
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils",
    "ui": "@/components/ui",
    "lib": "@/lib",
    "hooks": "@/hooks"
  },
  "registries": {
    "@serok": "https://serok.ethansup.net/r/{name}.json"
  },
  "iconLibrary": "lucide"
}
```

이 설정은 다음을 정의합니다:

- **style**: 컴포넌트 스타일 프리셋
- **rsc**: React Server Component 지원 여부
- **tsx**: TypeScript 사용 여부
- **tailwind**: 스타일 설정 및 경로 (필수 설치 요소 아님)
- **aliases**: 모듈 경로 별칭 정의
- **registries**: 네임스페이스 레지스트리 설정 (`@serok` 네임스페이스로 간편하게 컴포넌트 설치)
- **iconLibrary**: 아이콘 라이브러리 (Lucide 사용)

## 2단계: 경로 별칭 설정

### TypeScript 설정 업데이트

`tsconfig.json`에 경로 매핑을 추가하여 절대 경로를 사용할 수 있도록 하세요:

```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"],
      "@/components/*": ["./src/components/*"],
      "@/lib/*": ["./src/lib/*"],
      "@/hooks/*": ["./src/hooks/*"]
    }
  }
}
```

경로 별칭을 사용하면:
- 깊은 디렉토리 구조에서도 간단한 import 경로 사용 가능
- 코드 가독성 향상
- 파일 이동 시 import 경로 일괄 수정 불필요

### 번들러 설정 업데이트

번들러에서 경로 별칭을 사용할 수 있도록 설정하세요.

**Vite 예시:**

```ts
import path from "path";
import react from "@vitejs/plugin-react";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      "@": path.resolve(__dirname, "./src"),
    },
  },
});
```

**Next.js 예시:**

Next.js는 `tsconfig.json`의 paths를 자동으로 인식하므로 별도의 설정이 필요하지 않습니다.

## 3단계: 테마 및 컴포넌트 설치

shadcn CLI를 사용하여 테마와 필요한 컴포넌트를 설치하세요. 테마는 필수이며, 나머지 컴포넌트는 필요에 따라 선택적으로 설치할 수 있습니다.

### 방법 1: 네임스페이스 사용 (권장)

`components.json`에 registries를 설정한 경우, 간단한 네임스페이스로 설치할 수 있습니다:

```sh
# 테마 설치 (필수)
npx shadcn@latest add @serok/provider

# 원하는 컴포넌트 설치
npx shadcn@latest add @serok/button
npx shadcn@latest add @serok/checkbox
npx shadcn@latest add @serok/input
npx shadcn@latest add @serok/select
npx shadcn@latest add @serok/switch
```

### 방법 2: 전체 URL 사용

registries 설정 없이 직접 URL로도 설치할 수 있습니다:

```sh
# 테마 설치 (필수)
npx shadcn@latest add https://serok.ethansup.net/r/provider.json

# 원하는 컴포넌트 설치
npx shadcn@latest add https://serok.ethansup.net/r/button.json
npx shadcn@latest add https://serok.ethansup.net/r/checkbox.json
npx shadcn@latest add https://serok.ethansup.net/r/input.json
npx shadcn@latest add https://serok.ethansup.net/r/select.json
npx shadcn@latest add https://serok.ethansup.net/r/switch.json
```

shadcn이 설치 과정에서 필요한 모든 의존성(React Spectrum, 테마 등)을 자동으로 설치합니다.

## 4단계: 기본 설정

### Provider 설정

앱의 루트 컴포넌트에서 `SerokProvider`로 감싸세요:

```jsx
import { SerokProvider } from "@/ui/components/Provider"

export function App() {
  return (
    <SerokProvider>
      <YourAppContent />
    </SerokProvider>
  )
}
```

## 사용 예제

### 기본 버튼

```jsx
import { Button } from "@/ui/components/Button"

export function MyComponent() {
  return (
    <Button>
      클릭하기
    </Button>
  )
}
```

### 체크박스

```jsx
import { Checkbox } from "@/ui/components/Checkbox"
import { useState } from "react"

export function MyCheckbox() {
  const [isSelected, setIsSelected] = useState(false)

  return (
    <Checkbox
      isSelected={isSelected}
      onChange={setIsSelected}
    >
      동의합니다
    </Checkbox>
  )
}
```

### 완전한 폼 예제

```jsx
import { SerokProvider } from "@/ui/components/Provider"
import { Button } from "@/ui/components/Button"
import { Input } from "@/ui/components/Input"
import { Checkbox } from "@/ui/components/Checkbox"
import { useState } from "react"

export function MyForm() {
  const [formData, setFormData] = useState({
    name: "",
    agreed: false,
  })

  const handleSubmit = (e) => {
    e.preventDefault()
    console.log(formData)
  }

  return (
    <SerokProvider>
      <form onSubmit={handleSubmit} className="space-y-4">
        <Input
          label="이름"
          value={formData.name}
          onChange={(e) => setFormData({ ...formData, name: e.target.value })}
        />
        <Checkbox
          isSelected={formData.agreed}
          onChange={(agreed) => setFormData({ ...formData, agreed })}
        >
          약관에 동의합니다
        </Checkbox>
        <Button type="submit">제출</Button>
      </form>
    </SerokProvider>
  )
}
```

## 문제 해결

### 컴포넌트가 스타일이 적용되지 않음

- CSS 파일이 전역 스타일에 포함되어 있는지 확인하세요
- `components.json`의 경로가 올바른지 확인하세요

### 타입 오류 발생

- TypeScript 버전이 4.0 이상인지 확인하세요
- `tsconfig.json`의 경로가 올바른지 확인하세요

### Provider 오류

- `SerokProvider`가 앱의 최상위에 있는지 확인하세요
- 다른 Provider와의 순서를 확인하세요
