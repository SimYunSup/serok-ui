# 설치하기

프로젝트에 컴포넌트를 추가하려면 아래 단계를 따라주세요.

---

## 1단계: 설정 파일 생성

프로젝트 루트에 `components.json` 파일을 생성하고, CSS 파일 경로를 전역 CSS 파일 위치에 맞게 수정하세요.

```json
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "",
  "rsc": false,
  "tsx": true,
  "tailwind": {
    "config": "",
    "css": "{전역 CSS 파일 경로}",
    "baseColor": "stone",
    "cssVariables": true,
    "prefix": ""
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils",
    "ui": "@/components/ui",
    "lib": "@/lib",
    "hooks": "@/hooks"
  },
  "iconLibrary": "lucide"
}
```

---

## 2단계: 경로 별칭 설정

### TypeScript 설정 업데이트

`tsconfig.json`에 경로 매핑을 추가하세요:

```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

### 번들러 설정 업데이트

번들러에서 경로 별칭을 사용할 수 있도록 설정하세요. Vite 예시:

```ts
import path from "path";
import react from "@vitejs/plugin-react";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      "@": path.resolve(__dirname, "./src"),
    },
  },
});
```

---

## 3단계: 테마 및 컴포넌트 설치

다음 명령어를 사용하여 테마와 컴포넌트를 설치하세요:

```sh
# 테마 설치
npx shadcn@latest add https://simyunsup.github.io/serok-ui/r/provider.json

# 버튼 컴포넌트 설치
npx shadcn@latest add https://simyunsup.github.io/serok-ui/r/button.json
```

```jsx
import { SerokProvider } from "@/ui/components/Provider"
import { Button } from "@/ui/components/Button"

<SerokProvider>
  <Button>클릭/Button>
</SerokProvider>
