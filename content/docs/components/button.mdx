## Props

| Prop | Type | Description |
|------|------|-------------|
| `variant` | "accent" \| "primary" \| "secondary" \| "negative" | 버튼의 색상 스타일 |
| `style` | "fill" \| "outline" | 버튼의 스타일 (채워짐 또는 테두리만) |
| `size` | "s" \| "m" \| "l" \| "xl" | 버튼의 크기 |
| `staticColor` | "white" \| "black" | 색상 배경 위에 사용할 정적 색상 |
| `isDisabled` | boolean | 버튼 비활성화 여부 |
| `isPending` | boolean | 로딩 상태 여부 |
| `children` | React.ReactNode | 버튼 텍스트 또는 콘텐츠 |
| `onPress` | () => void | 버튼 클릭 이벤트 핸들러 |

이외의 Props들은 [React Spectrum Button](https://react-spectrum.adobe.com/react-spectrum/Button.html#props) 문서를 참고하세요.

## 기본 사용법

```tsx
import { Button } from "@/components/ui/Button";

export default function ButtonExample() {
  return (
    <Button variant="accent" size="m" style="fill">
      Click Me
    </Button>
  );
}
```

## 변형

### 색상 변형

```tsx
<Button variant="accent">Accent</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="primary">Primary</Button>
<Button variant="negative">Negative</Button>
<Button variant="white">White</Button>
<Button variant="black">Black</Button>
```

### 크기 변형

```tsx
<Button size="s">Small</Button>
<Button size="m">Medium</Button>
<Button size="l">Large</Button>
<Button size="xl">Extra Large</Button>
```

### 스타일 변형

```tsx
<Button style="fill">Fill</Button>
<Button style="outline">Outline</Button>
```

### 상태

```tsx
<Button isDisabled>Disabled</Button>
<Button isPending>Loading</Button>
```

## 예제

```tsx
import { Button } from "@/components/ui/Button";

export default function Example() {
  const handlePress = () => {
    console.log("Button pressed!");
  };

  return (
    <div style={{ display: "flex", gap: "8px" }}>
      <Button
        variant="accent"
        size="m"
        style="fill"
        onPress={handlePress}
      >
        Submit
      </Button>
      <Button
        variant="secondary"
        size="m"
        style="outline"
      >
        Cancel
      </Button>
    </div>
  );
}
```
