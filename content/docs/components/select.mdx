## 개요

셀렉트는 제한된 공간에서 여러 옵션 중 하나를 선택할 수 있는 드롭다운 컴포넌트입니다. 클릭하면 모든 옵션을 보여주는 목록이 나타나고, 사용자가 그 중 하나를 선택하면 닫힙니다. Serok UI의 셀렉트는 React Spectrum의 Picker를 기반으로 합니다.

## 빠른 시작

가장 기본적인 셀렉트 사용 방법입니다:

```tsx
import { Select, SelectItem } from '@/components/ui/Select';

export function MyComponent() {
  return (
    <Select label="옵션을 선택하세요">
      <SelectItem key="option1">옵션 1</SelectItem>
      <SelectItem key="option2">옵션 2</SelectItem>
      <SelectItem key="option3">옵션 3</SelectItem>
    </Select>
  );
}
```

## Props (속성)

| 속성 | 타입 | 필수 | 기본값 | 설명 |
|------|------|------|--------|------|
| `label` | `string \| ReactNode` | No | — | 셀렉트 위에 표시될 라벨 |
| `placeholder` | `string` | No | — | 선택된 항목이 없을 때 표시될 텍스트 |
| `selectedKey` | `string \| number` | No | — | 선택된 항목의 키 (제어 모드) |
| `defaultSelectedKey` | `string \| number` | No | — | 초기 선택된 항목의 키 (비제어 모드) |
| `onSelectionChange` | `(key: string \| number) => void` | No | — | 선택이 변경될 때 호출 함수 |
| `isDisabled` | `boolean` | No | `false` | 셀렉트 비활성화 여부 |
| `isLoading` | `boolean` | No | `false` | 로딩 상태 표시 |
| `isQuiet` | `boolean` | No | `false` | 미니멀 스타일, 테두리 숨김 |
| `isInvalid` | `boolean` | No | `false` | 유효성 검사 실패 상태 |
| `isRequired` | `boolean` | No | `false` | 필수 필드 표시 |
| `description` | `string` | No | — | 셀렉트 아래 표시될 설명 텍스트 |
| `errorMessage` | `string` | No | — | 유효성 검사 실패 메시지 |
| `children` | `SelectItem[]` | Yes | — | 셀렉트 옵션 (SelectItem 컴포넌트들) |

## SelectItem Props (옵션 속성)

| 속성 | 타입 | 필수 | 기본값 | 설명 |
|------|------|------|--------|------|
| `key` | `string \| number` | Yes | — | 옵션의 고유 식별자 |
| `children` | `ReactNode` | Yes | — | 옵션에 표시될 텍스트 또는 콘텐츠 |
| `isDisabled` | `boolean` | No | `false` | 특정 옵션 비활성화 여부 |
| `textValue` | `string` | No | — | 검색/필터링용 텍스트 |

## 상태 종류

- **활성 (Enabled)**: 정상적으로 선택 가능
- **비활성 (Disabled)** (`isDisabled={true}`): 선택 불가, 회색 처리됨
- **로딩 중 (Loading)** (`isLoading={true}`): 로딩 상태 표시
- **유효성 검사 실패 (Invalid)** (`isInvalid={true}`): 오류 상태
- **미니멀 (Quiet)** (`isQuiet={true}`): 미니멀 스타일, 테두리 숨김

```tsx

    <Select
      label="옵션 선택"

      <SelectItem key="opt2">옵션 2</SelectItem>
      <SelectItem key="opt3">옵션 3</SelectItem>
    </Select>
  );
}
```

### 로딩 상태

비동기 작업 중 로딩 상태를 표시하는 예제입니다.

```tsx
import { Select, SelectItem } from '@/components/ui/Select';
import { useState } from 'react';

export function LoadingExample() {
  const [isLoading, setIsLoading] = useState(false);

  const handleSelectionChange = async (key: string | number) => {
    setIsLoading(true);
    try {
      // 비동기 작업 시뮬레이션
      await new Promise(resolve => setTimeout(resolve, 1000));
      console.log('선택됨:', key);
    } finally {
      setIsLoading(false);
    }
  };

  return (
    <Select
      label="옵션을 선택하세요"
      isLoading={isLoading}
      onSelectionChange={handleSelectionChange}
    >
      <SelectItem key="opt1">옵션 1</SelectItem>
      <SelectItem key="opt2">옵션 2</SelectItem>
      <SelectItem key="opt3">옵션 3</SelectItem>
    </Select>
  );
}
```

### 동적 옵션 목록

서버에서 가져온 데이터로 옵션을 생성하는 예제입니다.

```tsx
import { Select, SelectItem } from '@/components/ui/Select';
import { useState, useEffect } from 'react';

export function DynamicOptionsExample() {
  const [options, setOptions] = useState<{ id: string; name: string }[]>([]);
  const [isLoading, setIsLoading] = useState(true);

  useEffect(() => {
    // 데이터 로드 시뮬레이션
    setTimeout(() => {
      setOptions([
        { id: '1', name: '서울' },
        { id: '2', name: '부산' },
        { id: '3', name: '대구' },
      ]);
      setIsLoading(false);
    }, 1000);
  }, []);

  return (
    <Select label="도시를 선택하세요" isLoading={isLoading}>
      {options.map(option => (
        <SelectItem key={option.id}>{option.name}</SelectItem>
      ))}
    </Select>
  );
}
```

## 자주 묻는 질문 (FAQ)

### Q: 여러 선택을 지원하나요?

A: 아니요, 셀렉트는 단일 선택만 지원합니다. 여러 선택이 필요하면 체크박스를 사용하세요.

### Q: 옵션을 그룹화할 수 있나요?

A: React Spectrum Picker의 Section 컴포넌트를 사용할 수 있습니다:

```tsx
import { Select, SelectItem } from '@/components/ui/Select';
import { Section } from '@react-spectrum/picker';

<Select label="선택하세요">
  <Section title="과일">
    <SelectItem key="apple">사과</SelectItem>
    <SelectItem key="banana">바나나</SelectItem>
  </Section>
  <Section title="채소">
    <SelectItem key="carrot">당근</SelectItem>
    <SelectItem key="broccoli">브로콜리</SelectItem>
  </Section>
</Select>
```

### Q: 옵션이 많을 때는?

A: Picker는 스크롤 가능한 드롭다운을 제공합니다. 검색 기능이 필요하면 React Spectrum의 ComboBox를 고려하세요.

## 실제 사용 패턴

### 1. 형식 선택 필드

가장 흔한 사용 패턴입니다:

```tsx
import { Select, SelectItem } from '@/components/ui/Select';
import { Button } from '@/components/ui/Button';
import { useState } from 'react';

export function FormSelectionExample() {
  const [category, setCategory] = useState('');

  const handleSubmit = () => {
    if (!category) {
      alert('카테고리를 선택하세요');
      return;
    }
    console.log('제출:', category);
  };

  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: '1rem' }}>
      <Select
        label="카테고리"
        selectedKey={category}
        onSelectionChange={setCategory}
        isRequired
      >
        <SelectItem key="electronics">전자제품</SelectItem>
        <SelectItem key="books">책</SelectItem>
        <SelectItem key="clothing">의류</SelectItem>
        <SelectItem key="food">음식</SelectItem>
      </Select>

      <Button variant="primary" onPress={handleSubmit}>
        제출
      </Button>
    </div>
  );
}
```

### 2. 필터링 기능

여러 셀렉트를 조합하여 필터링하는 예제입니다:

```tsx
import { Select, SelectItem } from '@/components/ui/Select';
import { useState } from 'react';

export function FilteringExample() {
  const [category, setCategory] = useState('');
  const [price, setPrice] = useState('');

  return (
    <div style={{ display: 'flex', gap: '1rem', flexDirection: 'column' }}>
      <h3>상품 필터</h3>

      <Select
        label="카테고리"
        selectedKey={category}
        onSelectionChange={setCategory}
        placeholder="선택하세요"
      >
        <SelectItem key="all">전체</SelectItem>
        <SelectItem key="electronics">전자제품</SelectItem>
        <SelectItem key="books">책</SelectItem>
        <SelectItem key="clothing">의류</SelectItem>
      </Select>

      <Select
        label="가격대"
        selectedKey={price}
        onSelectionChange={setPrice}
        placeholder="선택하세요"
      >
        <SelectItem key="all">전체</SelectItem>
        <SelectItem key="low">10,000원 이하</SelectItem>
        <SelectItem key="mid">10,000 ~ 50,000원</SelectItem>
        <SelectItem key="high">50,000원 이상</SelectItem>
      </Select>

      {(category || price) && (
        <p style={{ marginTop: '1rem' }}>
          필터: {category && `카테고리: ${category}`}
          {price && ` / 가격: ${price}`}
        </p>
      )}
    </div>
  );
}
```

### 3. 의존적 선택 (종속 셀렉트)

첫 번째 선택에 따라 두 번째 옵션이 변경되는 예제입니다:

```tsx
import { Select, SelectItem } from '@/components/ui/Select';
import { useState } from 'react';

export function DependentSelectExample() {
  const [country, setCountry] = useState('kr');

  const cities: Record<string, string[]> = {
    kr: ['서울', '부산', '대구'],
    us: ['뉴욕', '로스앤젤레스', '시카고'],
    jp: ['도쿄', '오사카', '교토'],
  };

  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: '1rem' }}>
      <Select
        label="국가"
        selectedKey={country}
        onSelectionChange={(value) => setCountry(value as string)}
      >
        <SelectItem key="kr">대한민국</SelectItem>
        <SelectItem key="us">미국</SelectItem>
        <SelectItem key="jp">일본</SelectItem>
      </Select>

      <Select label="도시">
        {cities[country]?.map(city => (
          <SelectItem key={city}>{city}</SelectItem>
        ))}
      </Select>
    </div>
  );
}
```
