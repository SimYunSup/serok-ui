## 개요

Tabs는 관련된 콘텐츠를 여러 패널로 구성하여 사용자가 한 번에 하나의 패널만 볼 수 있도록 하는 컴포넌트입니다. 탭은 일반적으로 복잡한 정보를 구성하거나 여러 보기 간에 전환하는 데 사용됩니다. Serok UI의 Tabs 컴포넌트는 React Spectrum의 Tabs를 확장하고 Serok 디자인 시스템에 맞는 사용자 정의 변형과 스타일을 제공합니다.

## 빠른 시작

가장 일반적인 사용 패턴을 보여주는 최소한의 작동 예제입니다.

```tsx
import { Tabs, TabList, TabPanels, Item } from '@/components/ui/Tabs';

export function MyComponent() {
  return (
    <Tabs>
      <TabList>
        <Item key="tab1">탭 1</Item>
        <Item key="tab2">탭 2</Item>
        <Item key="tab3">탭 3</Item>
      </TabList>
      <TabPanels>
        <Item key="tab1">탭 1의 콘텐츠</Item>
        <Item key="tab2">탭 2의 콘텐츠</Item>
        <Item key="tab3">탭 3의 콘텐츠</Item>
      </TabPanels>
    </Tabs>
  );
}
```

## Props

### Tabs Props

| Prop | Type | 필수 | 기본값 | 설명 |
|------|------|------|-------|------|
| `selectedKey` | `Key` | No | — | 제어된 선택 탭의 키 |
| `defaultSelectedKey` | `Key` | No | — | 비제어 초기 선택 탭의 키 |
| `onSelectionChange` | `(key: Key) => void` | No | — | 선택된 탭이 변경될 때 호출됨 |
| `isDisabled` | `boolean` | No | `false` | 모든 탭 비활성화 |
| `disabledKeys` | `Iterable<Key>` | No | — | 비활성화할 특정 탭의 키 목록 |
| `variant` | `"default" \| "compact" \| "emphasized"` | No | `"default"` | 시각적 스타일 변형 |
| `orientation` | `"horizontal" \| "vertical"` | No | `"horizontal"` | 탭 목록의 방향 |
| `density` | `"compact" \| "regular"` | No | `"regular"` | 탭 간격 밀도 |
| `children` | `ReactNode` | Yes | — | TabList와 TabPanels 컴포넌트 |

**추가 참고사항**:

- 모든 props는 React Spectrum 명명 규칙을 따릅니다
- Props는 대소문자를 구분합니다
- 기본값은 코드에 나타나는 대로 정확하게 표시됩니다
- React Spectrum의 `@react-spectrum/tabs` 컴포넌트의 모든 props를 확장합니다

### Item Props

| Prop | Type | 필수 | 설명 |
|------|------|------|------|
| `key` | `Key` | Yes | 탭/패널의 고유 식별자 |
| `textValue` | `string` | No | 탭의 텍스트 표현 (접근성용) |
| `children` | `ReactNode` | Yes | 탭 레이블 또는 패널 콘텐츠 |

## 변형 & 상태

### 시각적 변형

| 변형 | Props | 사용 사례 |
|------|-------|---------|
| 기본 | `variant="default"` | 표준 탭, 중립 스타일 |
| 컴팩트 | `variant="compact"` | 공간이 제한된 UI, 더 작은 탭 |
| 강조 | `variant="emphasized"` | 중요한 내비게이션, 강조된 선택 표시 |

### 방향

| 방향 | Props | 사용 사례 |
|------|-------|---------|
| 수평 | `orientation="horizontal"` | 기본, 탭이 상단에 가로로 배치 |
| 수직 | `orientation="vertical"` | 사이드바 스타일, 탭이 측면에 세로로 배치 |

### 동작 상태

- **활성화됨**: 정상 상호작용 가능
- **선택됨**: 현재 활성 탭 및 표시되는 패널
- **비활성화됨** (`isDisabled={true}`): 모든 탭 상호작용 불가능
- **부분 비활성화** (`disabledKeys={["key1", "key2"]}`): 특정 탭만 비활성화

## 예제

### 기본 사용법

Tabs 컴포넌트의 가장 간단한 사용 방법입니다.

```tsx
import { Tabs, TabList, TabPanels, Item } from '@/components/ui/Tabs';

export function BasicExample() {
  return (
    <Tabs>
      <TabList>
        <Item key="home">홈</Item>
        <Item key="profile">프로필</Item>
        <Item key="settings">설정</Item>
      </TabList>
      <TabPanels>
        <Item key="home">
          <h2>홈 페이지</h2>
          <p>홈 페이지에 오신 것을 환영합니다.</p>
        </Item>
        <Item key="profile">
          <h2>프로필</h2>
          <p>여기에서 프로필 정보를 확인할 수 있습니다.</p>
        </Item>
        <Item key="settings">
          <h2>설정</h2>
          <p>애플리케이션 설정을 관리합니다.</p>
        </Item>
      </TabPanels>
    </Tabs>
  );
}
```

### 제어 Tabs

부모 컴포넌트에 의해 상태가 관리되는 탭입니다.

```tsx
import { Tabs, TabList, TabPanels, Item } from '@/components/ui/Tabs';
import { useState } from 'react';

export function ControlledExample() {
  const [selectedTab, setSelectedTab] = useState('overview');

  return (
    <div>
      <p>현재 선택된 탭: {selectedTab}</p>
      <Tabs
        selectedKey={selectedTab}
        onSelectionChange={setSelectedTab}
      >
        <TabList>
          <Item key="overview">개요</Item>
          <Item key="details">세부정보</Item>
          <Item key="reviews">리뷰</Item>
        </TabList>
        <TabPanels>
          <Item key="overview">개요 콘텐츠</Item>
          <Item key="details">세부정보 콘텐츠</Item>
          <Item key="reviews">리뷰 콘텐츠</Item>
        </TabPanels>
      </Tabs>
    </div>
  );
}
```

### 동적 탭

동적으로 생성된 탭 목록입니다.

```tsx
import { Tabs, TabList, TabPanels, Item } from '@/components/ui/Tabs';

export function DynamicExample() {
  const tabs = [
    { id: '1', title: '월요일', content: '월요일 일정' },
    { id: '2', title: '화요일', content: '화요일 일정' },
    { id: '3', title: '수요일', content: '수요일 일정' },
    { id: '4', title: '목요일', content: '목요일 일정' },
    { id: '5', title: '금요일', content: '금요일 일정' },
  ];

  return (
    <Tabs>
      <TabList>
        {tabs.map((tab) => (
          <Item key={tab.id}>{tab.title}</Item>
        ))}
      </TabList>
      <TabPanels>
        {tabs.map((tab) => (
          <Item key={tab.id}>
            <h3>{tab.title}</h3>
            <p>{tab.content}</p>
          </Item>
        ))}
      </TabPanels>
    </Tabs>
  );
}
```

## 접근성

### 키보드 지원

| 키 | 동작 |
|----|------|
| `Tab` | 탭 목록으로 포커스 이동 또는 다음 요소로 이동 |
| `Arrow Left/Right` | 수평 방향에서 이전/다음 탭으로 이동 |
| `Arrow Up/Down` | 수직 방향에서 이전/다음 탭으로 이동 |
| `Home` | 첫 번째 탭으로 이동 |
| `End` | 마지막 탭으로 이동 |
| `Enter` 또는 `Space` | 포커스된 탭 활성화 |

### WCAG 준수

- Level AA: 탭은 키보드 네비게이션 및 스크린 리더를 지원합니다
- 포커스 표시: 키보드 사용자를 위한 명확한 포커스 표시
- 색상 독립적: 정보 전달을 위해 색상에만 의존하지 않습니다
- 시맨틱 HTML: 적절한 ARIA 역할 및 속성 사용

## 모범 사례

- 탭 레이블은 짧고 명확하게 유지하세요 (1-2 단어)
- 너무 많은 탭을 사용하지 마세요 (5-7개 이하 권장)
- 관련된 콘텐츠를 그룹화하는 데 탭을 사용하세요
- 탭이 선형 워크플로우를 나타내는 경우 스텝퍼(Stepper)를 고려하세요
- 모바일에서는 탭 대신 아코디언이나 다른 패턴을 고려하세요
- 각 탭에 충분한 콘텐츠가 있는지 확인하세요
- 탭 키는 일관되고 예측 가능하게 유지하세요

## 일반적인 문제

**문제**: TabList와 TabPanels의 Item 키가 일치하지 않습니다
**해결책**: TabList와 TabPanels의 각 Item이 동일한 키를 가지고 있는지 확인하세요. 키가 일치해야 탭과 콘텐츠가 올바르게 연결됩니다.

**문제**: onSelectionChange 핸들러가 호출되지 않습니다
**해결책**: `selectedKey`와 `onSelectionChange`를 함께 사용하여 제어 컴포넌트를 만들거나, `defaultSelectedKey`만 사용하여 비제어 컴포넌트를 만드세요.

**문제**: 특정 탭이 비활성화되지 않습니다
**해결책**: `disabledKeys` prop에 배열이나 Set을 전달하세요: `disabledKeys={['key1', 'key2']}` 또는 `disabledKeys={new Set(['key1'])}`

**문제**: 수직 탭이 제대로 정렬되지 않습니다
**해결책**: 부모 컨테이너에 적절한 높이가 설정되어 있는지 확인하세요. 수직 탭은 높이를 채우기 위해 충분한 공간이 필요합니다.
