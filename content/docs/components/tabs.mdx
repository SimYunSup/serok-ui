## 개요

Tabs는 관련된 콘텐츠를 여러 패널로 구성하여 사용자가 한 번에 하나의 패널만 볼 수 있도록 하는 컴포넌트입니다. 탭은 일반적으로 복잡한 정보를 구성하거나 여러 보기 간에 전환하는 데 사용됩니다. Serok UI의 Tabs 컴포넌트는 React Spectrum의 Tabs를 확장하고 Serok 디자인 시스템에 맞는 사용자 정의 스타일을 제공합니다.

## 빠른 시작

가장 일반적인 사용 패턴을 보여주는 최소한의 작동 예제입니다.

## Props (속성)

### Tabs Props

| 속성 | 타입 | 필수 | 기본값 | 설명 |
| ------ | ------ | ------ | ------- | ------ |
| `selectedKey` | `Key` | No | — | 제어된 선택 탭의 키 |
| `defaultSelectedKey` | `Key` | No | — | 비제어 초기 선택 탭의 키 |
| `onSelectionChange` | `(key: Key) => void` | No | — | 선택된 탭이 변경될 때 호출됨 |
| `isDisabled` | `boolean` | No | `false` | 모든 탭 비활성화 |
| `disabledKeys` | `Iterable<Key>` | No | — | 비활성화할 특정 탭의 키 목록 |
| `orientation` | `"horizontal" \| "vertical"` | No | `"horizontal"` | 탭 목록의 방향 |
| `density` | `"compact" \| "regular"` | No | `"regular"` | 탭 간격 밀도 |
| `children` | `ReactNode` | Yes | — | TabList와 TabPanels 컴포넌트 |

### TabItem Props

| 속성 | 타입 | 필수 | 설명 |
| ------ | ------ | ------ | ------ |
| `key` | `Key` | Yes | 탭/패널의 고유 식별자 |
| `textValue` | `string` | No | 탭의 텍스트 표현 (접근성용) |
| `children` | `ReactNode` | Yes | 탭 레이블 또는 패널 콘텐츠 |

## 변형 및 상태

### 방향

| 방향 | Props | 사용 사례 |
| ------ | ------- | --------- |
| 수평 | `orientation="horizontal"` | 기본, 탭이 상단에 가로로 배치 |
| 수직 | `orientation="vertical"` | 사이드바 스타일, 탭이 측면에 세로로 배치 |

### 상태 종류

- **활성화됨**: 정상 상호작용 가능
- **선택됨**: 현재 활성 탭 및 표시되는 패널
- **비활성화됨** (`isDisabled={true}`): 모든 탭 상호작용 불가능
- **부분 비활성화** (`disabledKeys={["key1", "key2"]}`): 특정 탭만 비활성화

## 사용 예제

### 기본 사용법

Tabs 컴포넌트의 가장 간단한 사용 방법입니다.

```tsx
import { Tabs, TabList, TabPanels, TabItem } from '@/components/ui/Tabs';

export function BasicExample() {
  return (
    <Tabs>
      <TabList>
        <TabItem key="home">홈</TabItem>
        <TabItem key="profile">프로필</TabItem>
        <TabItem key="settings">설정</TabItem>
      </TabList>
      <TabPanels>
        <TabItem key="home">
          <h2>홈 페이지</h2>
          <p>홈 페이지에 오신 것을 환영합니다.</p>
        </TabItem>
        <TabItem key="profile">
          <h2>프로필</h2>
          <p>여기에서 프로필 정보를 확인할 수 있습니다.</p>
        </TabItem>
        <TabItem key="settings">
          <h2>설정</h2>
          <p>애플리케이션 설정을 관리합니다.</p>
        </TabItem>
      </TabPanels>
    </Tabs>
  );
}
```

### 제어 Tabs

부모 컴포넌트에 의해 상태가 관리되는 탭입니다.

```tsx
import { Tabs, TabList, TabPanels, TabItem } from '@/components/ui/Tabs';
import { useState } from 'react';

export function ControlledExample() {
  const [selectedTab, setSelectedTab] = useState('overview');

  return (
    <div>
      <p>현재 선택된 탭: {selectedTab}</p>
      <Tabs
        selectedKey={selectedTab}
        onSelectionChange={setSelectedTab}
      >
        <TabList>
          <TabItem key="overview">개요</TabItem>
          <TabItem key="details">세부정보</TabItem>
          <TabItem key="reviews">리뷰</TabItem>
        </TabList>
        <TabPanels>
          <TabItem key="overview">개요 콘텐츠</TabItem>
          <TabItem key="details">세부정보 콘텐츠</TabItem>
          <TabItem key="reviews">리뷰 콘텐츠</TabItem>
        </TabPanels>
      </Tabs>
    </div>
  );
}
```

### 동적 탭

동적으로 생성된 탭 목록입니다.

```tsx
import { Tabs, TabList, TabPanels, TabItem } from '@/components/ui/Tabs';

export function DynamicExample() {
  const tabs = [
    { id: '1', title: '월요일', content: '월요일 일정' },
    { id: '2', title: '화요일', content: '화요일 일정' },
    { id: '3', title: '수요일', content: '수요일 일정' },
    { id: '4', title: '목요일', content: '목요일 일정' },
    { id: '5', title: '금요일', content: '금요일 일정' },
  ];

  return (
    <Tabs>
      <TabList>
        {tabs.map((tab) => (
          <TabItem key={tab.id}>{tab.title}</TabItem>
        ))}
      </TabList>
      <TabPanels>
        {tabs.map((tab) => (
          <TabItem key={tab.id}>
            <h3>{tab.title}</h3>
            <p>{tab.content}</p>
          </TabItem>
        ))}
      </TabPanels>
    </Tabs>
  );
}
```

## 컴포넌트 정보

- **소스**: `lib/ui/Tabs/index.tsx`
- **스타일**: `lib/ui/Tabs/styles.css`
- **내보내기**: `@/components/ui/Tabs`에서 이름 있는 내보내기 (named export)
- **기반**: React Spectrum (@react-spectrum/tabs)
- **CSS 커스터마이징**: 지원
- **테스팅**: `data-testid="tabs"` 사용
