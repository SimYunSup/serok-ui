## Props

| Prop | Type | Description |
|------|------|-------------|
| `isSelected` | boolean | 체크박스의 선택 상태 (제어되는 값) |
| `defaultSelected` | boolean | 초기 선택 상태 (제어되지 않는 값) |
| `size` | "s" \| "m" \| "l" \| "xl" | 체크박스의 크기 |
| `isIndeterminate` | boolean | 불확정 상태 (부분 선택) |
| `isInvalid` | boolean | 유효성 검사 실패 여부 |
| `isDisabled` | boolean | 체크박스 비활성화 여부 |
| `isReadOnly` | boolean | 읽기 전용 모드 |
| `isRequired` | boolean | 필수 입력 여부 |
| `children` | React.ReactNode | 라벨 텍스트 |
| `onChange` | (isSelected: boolean) => void | 값 변경 이벤트 핸들러 |

이외의 Props들은 [React Spectrum Checkbox](https://react-spectrum.adobe.com/react-spectrum/Checkbox.html#props) 문서를 참고하세요.

## 기본 사용법

```tsx
import { Checkbox } from "@/components/ui/Checkbox";
import { useState } from "react";

export default function CheckboxExample() {
  const [selected, setSelected] = useState(false);

  return (
    <Checkbox
      isSelected={selected}
      onChange={setSelected}
    >
      Remember me
    </Checkbox>
  );
}
```

## 예제

```tsx
import { Checkbox } from "@/components/ui/Checkbox";
import { useState } from "react";

export default function CheckboxExample() {
  const [terms, setTerms] = useState(false);
  const [newsletter, setNewsletter] = useState(false);

  return (
    <form style={{ display: "flex", flexDirection: "column", gap: "12px" }}>
      <Checkbox
        isSelected={terms}
        onChange={setTerms}
        isRequired
      >
        I agree to the terms and conditions
      </Checkbox>
      <Checkbox
        isSelected={newsletter}
        onChange={setNewsletter}
      >
        Subscribe to our newsletter
      </Checkbox>
    </form>
  );
}
```
