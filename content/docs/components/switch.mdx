## 개요

스위치는 사용자가 이진 옵션을 켜거나 끌 수 있는 양식 컨트롤입니다. 스위치는 일반적으로 설정, 기본 설정 및 기능 토글에 사용됩니다. Serok UI의 Switch 컴포넌트는 React Spectrum의 Switch를 확장하고 Serok 디자인 시스템에 맞는 사용자 정의 변형과 스타일을 제공합니다.

## 빠른 시작

가장 일반적인 사용 패턴을 보여주는 최소한의 작동 예제입니다.

```tsx
import { Switch } from '@/components/ui/Switch';

export function MyComponent() {
  return <Switch>알림 활성화</Switch>;
}
```

## Props (속성)

| 속성 | 타입 | 필수 | 기본값 | 설명 |
| ------ | ------ | ------ | ------- | ------ |
| `isSelected` | `boolean` | No | — | 제어된 선택 상태 |
| `defaultSelected` | `boolean` | No | `false` | 비제어 초기 선택 상태 |
| `onChange` | `(isSelected: boolean) => void` | No | — | 선택 상태가 변경될 때 호출됨 |
| `isDisabled` | `boolean` | No | `false` | 사용자 상호작용 비활성화 |
| `isReadOnly` | `boolean` | No | `false` | 읽기 전용 모드, 상호작용 불가능 |
| `variant` | `"default" \| "accent" \| "secondary"` | No | `"default"` | 시각적 스타일 변형 |
| `isEmphasized` | `boolean` | No | `false` | 강조 스타일 적용 |
| `children` | `ReactNode` | Yes | — | 스위치 라벨 텍스트 또는 콘텐츠 |

## 변형 및 상태

### 시각적 변형

| 변형 | Props | 사용 사례 |
| ------ | ------- | --------- |
| 기본 | `variant="default"` | 표준 스위치, 중립 스타일 |
| 강조 | `variant="accent"` | 중요한 토글, 강조된 스위치 |
| 보조 | `variant="secondary"` | 덜 중요한 토글, 보조 선택 |

### 상태 종류


<PreviewWrapper>
  <Switch variant="accent" isDisabled isSelected>비활성화됨</Switch>
  <Switch variant="accent" isReadOnly isSelected>읽기 전용</Switch>
</PreviewWrapper>

- **활성화됨**: 정상 상호작용 가능
- **선택됨** (`isSelected={true}`): 스위치가 켜짐
- **선택 안 됨** (`isSelected={false}`): 스위치가 꺼짐
- **비활성화됨** (`isDisabled={true}`): 상호작용 불가능, 회색 처리됨
- **읽기 전용** (`isReadOnly={true}`): 상태를 표시하지만 상호작용 불가능

## 사용 예제

### 기본 사용법

Switch 컴포넌트의 가장 간단한 사용 방법입니다.

```tsx
import { Switch } from '@/components/ui/Switch';

export function BasicExample() {
  return <Switch>알림 활성화</Switch>;
}
```

### 비제어 Switch

자신의 상태를 스스로 관리하는 스위치입니다.

```tsx
import { Switch } from '@/components/ui/Switch';

export function UncontrolledExample() {
  return (
    <Switch defaultSelected={false}>
      뉴스레터 구독
    </Switch>
  );
}
```

### 제어 Switch

부모 컴포넌트에 의해 상태가 관리되는 스위치입니다.

```tsx
import { Switch } from '@/components/ui/Switch';
import { useState } from 'react';

export function ControlledExample() {
  const [isSelected, setIsSelected] = useState(false);

  return (
    <Switch
      isSelected={isSelected}
      onChange={setIsSelected}
    >
      다크 모드
    </Switch>
  );
}
```

### 모든 변형

사용 가능한 모든 시각적 변형을 보여줍니다.

```tsx
import { Switch } from '@/components/ui/Switch';

export function VariantsExample() {
  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: '1rem' }}>
      <Switch variant="default">기본</Switch>
      <Switch variant="accent">강조</Switch>
      <Switch variant="secondary">보조</Switch>
    </div>
  );
}
```

### 비활성화 상태

비활성화된 스위치 상태를 보여줍니다.

```tsx
import { Switch } from '@/components/ui/Switch';

export function DisabledExample() {
  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: '1rem' }}>
      <Switch isDisabled>비활성화 (꺼짐)</Switch>
      <Switch isDisabled isSelected={true}>
        비활성화 (켜짐)
      </Switch>
    </div>
  );
}
```

### 읽기 전용 Switch

읽기 전용 스위치 상태를 보여줍니다.

```tsx
import { Switch } from '@/components/ui/Switch';

export function ReadOnlyExample() {
  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: '1rem' }}>
      <Switch isReadOnly>읽기 전용 (꺼짐)</Switch>
      <Switch isReadOnly isSelected={true}>
        읽기 전용 (켜짐)
      </Switch>
    </div>
  );
}
```

## CSS 커스터마이제이션

Switch 컴포넌트는 CSS를 통해 스타일을 자유롭게 커스터마이징할 수 있습니다. **CSS 변수보다는 일반 CSS 속성을 직접 사용하는 것을 권장합니다.** 이 방법이 더 직관적이고 유지보수가 쉽습니다.

### 기본 CSS 커스터마이징

`className`을 통해 스위치에 커스텀 스타일을 적용할 수 있습니다:

```tsx
import { Switch } from '@/components/ui/Switch';
import './custom-switch-styles.css';

export function CustomStyleExample() {
  return <Switch variant="default" className="custom-switch">토글</Switch>;
}
```

```css
/* custom-switch-styles.css */
.custom-switch input[type="checkbox"] {
  accent-color: #e91e63;           /* 스위치 강조 색상 */
  width: 3rem;                     /* 스위치 너비 */
  height: 1.75rem;                 /* 스위치 높이 */
}

.custom-switch {
  color: #e91e63;                  /* 라벨 텍스트 색상 */
  font-weight: 600;                /* 라벨 폰트 굵기 */
}
```

### 인라인 스타일

간단한 스타일 변경은 `style` 속성을 사용할 수도 있습니다:

```tsx
import { Switch } from '@/components/ui/Switch';

export function InlineStyleExample() {
  return (
    <Switch
      variant="default"
      style={{
        fontSize: '1.1rem',
        fontWeight: 600
      }}
    >
      알림 활성화
    </Switch>
  );
}
```
