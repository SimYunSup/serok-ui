## Props

| Prop | Type | Description |
|------|------|-------------|
| `isSelected` | boolean | 스위치의 선택 상태 (제어되는 값) |
| `defaultSelected` | boolean | 초기 선택 상태 (제어되지 않는 값) |
| `isDisabled` | boolean | 스위치 비활성화 여부 |
| `isReadOnly` | boolean | 읽기 전용 모드 |
| `isEmphasized` | boolean | 강조 시각 스타일 적용 |
| `children` | React.ReactNode | 라벨 텍스트 |
| `onChange` | (isSelected: boolean) => void | 값 변경 이벤트 핸들러 |

이외의 Props들은 [React Spectrum Switch](https://react-spectrum.adobe.com/react-spectrum/Switch.html#props) 문서를 참고하세요.

## 기본 사용법

```tsx
import { Switch } from "@/components/ui/Switch";
import { useState } from "react";

export default function SwitchExample() {
  const [enabled, setEnabled] = useState(false);

  return (
    <Switch
      isSelected={enabled}
      onChange={setEnabled}
    >
      {enabled ? "Enabled" : "Disabled"}
    </Switch>
  );
}
```

## 예제

```tsx
import { Switch } from "@/components/ui/Switch";
import { useState } from "react";

export default function SettingsExample() {
  const [darkMode, setDarkMode] = useState(false);
  const [notifications, setNotifications] = useState(true);

  return (
    <div style={{ display: "flex", flexDirection: "column", gap: "16px" }}>
      <div style={{ display: "flex", alignItems: "center", justifyContent: "space-between" }}>
        <label>Dark Mode</label>
        <Switch
          isSelected={darkMode}
          onChange={setDarkMode}
        />
      </div>
      <div style={{ display: "flex", alignItems: "center", justifyContent: "space-between" }}>
        <label>Notifications</label>
        <Switch
          isSelected={notifications}
          onChange={setNotifications}
        />
      </div>
    </div>
  );
}
```
