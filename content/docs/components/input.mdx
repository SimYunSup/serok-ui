## Props

| Prop | Type | Description |
|------|------|-------------|
| `id` | string | 입력 필드의 고유 ID |
| `size` | "s" \| "m" \| "l" \| "xl" | 입력 필드의 크기 |
| `value` | string | 입력 필드의 값 (제어되는 값) |
| `defaultValue` | string | 입력 필드의 초기 값 (제어되지 않는 값) |
| `isInvalid` | boolean | 유효성 검사 실패 여부 |
| `validationState` | "valid" \| "invalid" | 유효성 검사 상태 |
| `isDisabled` | boolean | 입력 필드 비활성화 여부 |
| `isReadOnly` | boolean | 읽기 전용 모드 |
| `isQuiet` | boolean | 테두리 없이 표시할 여부 |
| `isRequired` | boolean | 필수 입력 여부 |
| `placeholder` | string | 플레이스홀더 텍스트 |
| `type` | "text" \| "email" \| "password" \| "tel" \| "url" | 입력 필드의 타입 |
| `onChange` | (value: string) => void | 값 변경 이벤트 핸들러 |
| `label` | string | 입력 필드의 라벨 |
| `description` | string | 입력 필드의 설명 텍스트 |
| `errorMessage` | string | 유효성 검사 실패 시 오류 메시지 |

이외의 Props들은 [React Spectrum TextField](https://react-spectrum.adobe.com/react-spectrum/TextField.html#props) 문서를 참고하세요.

## 기본 사용법

```tsx
import { Input } from "@/components/ui/Input";
import { useState } from "react";

export default function InputExample() {
  const [value, setValue] = useState("");

  return (
    <Input
      id="username"
      placeholder="Enter username"
      value={value}
      onChange={(e) => setValue(e.target.value)}
    />
  );
}
```

## 예제

```tsx
import { Input } from "@/components/ui/Input";
import { useState } from "react";

export default function LoginForm() {
  const [email, setEmail] = useState("");
  const [password, setPassword] = useState("");

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    console.log("Email:", email);
    console.log("Password:", password);
  };

  return (
    <form onSubmit={handleSubmit} style={{ display: "flex", flexDirection: "column", gap: "12px" }}>
      <Input
        id="email"
        type="email"
        placeholder="Email address"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
        size="m"
      />
      <Input
        id="password"
        type="password"
        placeholder="Password"
        value={password}
        onChange={(e) => setPassword(e.target.value)}
        size="m"
      />
    </form>
  );
}
```
