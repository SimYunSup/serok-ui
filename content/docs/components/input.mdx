## 개요

인풋은 사용자가 텍스트를 입력하고 편집할 수 있는 폼 컨트롤입니다. 일반적인 텍스트 입력 외에도 이메일, 비밀번호, 전화번호, URL 등 다양한 입력 타입을 지원합니다. Serok UI의 인풋 컴포넌트는 React Spectrum의 TextField를 기반으로 합니다.

## 빠른 시작

가장 기본적인 인풋 사용 방법입니다:

```tsx
import { Input } from '@/components/ui/Input';

export function MyComponent() {
  return <Input label="사용자명" placeholder="이름을 입력하세요" />;
}
```

## Props (속성)

| 속성 | 타입 | 필수 | 기본값 | 설명 |
| ------ | ------ | ------ | -------- | ------ |
| `label` | `string \| ReactNode` | No | — | 인풋 위에 표시될 라벨 |
| `placeholder` | `string` | No | — | 입력창이 비어있을 때 표시될 텍스트 |
| `type` | `"text" \| "email" \| "password" \| "tel" \| "url"` | No | `"text"` | 입력 타입 |
| `value` | `string` | No | — | 입력 값 (제어 모드) |
| `defaultValue` | `string` | No | — | 초기 입력 값 (비제어 모드) |
| `isDisabled` | `boolean` | No | `false` | 입력 비활성화 여부 |
| `isReadOnly` | `boolean` | No | `false` | 읽기 전용 모드 |
| `isRequired` | `boolean` | No | `false` | 필수 필드 표시 |
| `isInvalid` | `boolean` | No | `false` | 유효성 검사 실패 상태 |
| `validationState` | `"valid" \| "invalid"` | No | — | 유효성 검사 상태 |
| `errorMessage` | `string` | No | — | 유효성 검사 실패 메시지 |
| `description` | `string` | No | — | 입력창 아래 표시될 설명 텍스트 |
| `onChange` | `(value: string) => void` | No | — | 입력 값 변경 시 호출 함수 |
| `isQuiet` | `boolean` | No | `false` | 미니멀 스타일, 테두리 숨김 |
| `autoFocus` | `boolean` | No | `false` | 마운트 시 자동 포커스 |
| `maxLength` | `number` | No | — | 최대 입력 글자 수 |

## 입력 타입

### 지원하는 입력 타입

| 타입 | Props | 사용 사례 |
| ------ | ------- | ---------- |
| 텍스트 | `type="text"` | 일반 텍스트 입력 (기본값) |
| 이메일 | `type="email"` | 이메일 주소 입력 |
| 비밀번호 | `type="password"` | 비밀번호 입력 (텍스트 숨김) |
| 전화번호 | `type="tel"` | 전화번호 입력 |
| URL | `type="url"` | 웹 주소 입력 |

### 상태 종류

- **활성 (Enabled)**: 정상적으로 입력 가능
- **비활성 (Disabled)** (`isDisabled={true}`): 입력 불가, 회색 처리됨
- **읽기 전용 (Read-only)** (`isReadOnly={true}`): 값 표시만 가능, 편집 불가
- **유효성 검사 실패 (Invalid)** (`isInvalid={true}`): 오류 상태
- **미니멀 (Quiet)** (`isQuiet={true}`): 미니멀 스타일, 테두리 숨김

### 유효성 검사

유효성 검사와 오류 메시지를 표시하는 예제입니다.

```tsx
import { Input } from '@/components/ui/Input';
import { useState } from 'react';

export function ValidationExample() {
  const [email, setEmail] = useState('');
  const [error, setError] = useState('');

  const validateEmail = (value: string) => {
    const isValid = /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(value);
    if (!isValid && value) {
      setError('올바른 이메일 주소를 입력해주세요');
    } else {
      setError('');
    }
    setEmail(value);
  };

  return (
    <Input
      label="이메일"
      type="email"
      value={email}
      onChange={validateEmail}
      isInvalid={!!error}
      errorMessage={error}
      description="귀하의 이메일은 공개되지 않습니다"
    />
  );
}
```

### 검색 입력

검색 기능이 있는 인풋 예제입니다.

```tsx
import { Input } from '@/components/ui/Input';
import { useState } from 'react';

export function SearchExample() {
  const [searchValue, setSearchValue] = useState('');
  const [results, setResults] = useState<string[]>([]);

  const handleSearch = (value: string) => {
    setSearchValue(value);

    if (value.length < 2) {
      setResults([]);
      return;
    }

    // 검색 시뮬레이션
    const mockData = ['Apple', 'Apricot', 'Android', 'Amazon'];
    setResults(
      mockData.filter(item =>
        item.toLowerCase().includes(value.toLowerCase())
      )
    );
  };

  return (
    <div>
      <Input
        label="검색"
        type="text"
        value={searchValue}
        onChange={handleSearch}
        placeholder="검색어를 입력하세요"
        description={results.length > 0 ? `${results.length}개의 결과` : ''}
      />

      {results.length > 0 && (
        <ul style={{ marginTop: '1rem', listStyle: 'none', padding: 0 }}>
          {results.map((result, index) => (
            <li key={index} style={{ padding: '0.5rem', borderBottom: '1px solid #eee' }}>
              {result}
            </li>
          ))}
        </ul>
      )}
    </div>
  );
}
```

## CSS 커스터마이제이션

인풋 컴포넌트는 CSS를 통해 스타일을 자유롭게 커스터마이징할 수 있습니다. **CSS 변수보다는 일반 CSS 속성을 직접 사용하는 것을 권장합니다.** 이 방법이 더 직관적이고 유지보수가 쉽습니다.

### 기본 CSS 커스터마이징

`className`을 통해 인풋에 커스텀 스타일을 적용할 수 있습니다:

```tsx
import { Input } from '@/components/ui/Input';
import './custom-input-styles.css';

export function CustomStyleExample() {
  return <Input label="커스텀" className="custom-input" />;
}
```

```css
/* custom-input-styles.css */
.custom-input input {
  border: 2px solid #e91e63;       /* 테두리 색상 */
  border-radius: 8px;              /* 둥근 모서리 */
  padding: 0.75rem 1rem;           /* 패딩 */
  font-size: 1rem;                 /* 폰트 크기 */
}

.custom-input input:focus {
  border-color: #c2185b;           /* 포커스 시 테두리 색상 */
  outline: none;
  box-shadow: 0 0 0 3px rgba(233, 30, 99, 0.1);
}

.custom-input input::placeholder {
  color: #9ca3af;                  /* 플레이스홀더 색상 */
}
```

## 자주 묻는 질문 (FAQ)

### Q: 인풋 값을 동적으로 검증할 수 있나요?

A: 네, `onChange` 핸들러에서 실시간 검증할 수 있습니다:

```tsx
const [email, setEmail] = useState('');
const [error, setError] = useState('');

const handleEmailChange = (value: string) => {
  setEmail(value);
  const isValid = /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(value);
  setError(isValid || !value ? '' : '올바른 이메일을 입력하세요');
};
```

### Q: 인풋에서 값을 초기화할 수 있나요?

A: 네, 상태를 `''`로 초기화하거나 `defaultValue`를 사용하세요:

```tsx
const [value, setValue] = useState('');

const reset = () => setValue('');

return (
  <>
    <Input value={value} onChange={setValue} />
    <button onClick={reset}>초기화</button>
  </>
);
```

### Q: 숫자만 입력받을 수 있나요?

A: 네, `onChange`에서 필터링하거나 유효성 검사하세요:

```tsx
const handleNumberChange = (value: string) => {
  const numValue = value.replace(/[^0-9]/g, '');
  setNumber(numValue);
};
```

## 실제 사용 패턴

### 1. 로그인 폼

가장 흔한 사용 패턴입니다:

```tsx
import { Input } from '@/components/ui/Input';
import { Button } from '@/components/ui/Button';
import { useState } from 'react';

export function LoginFormExample() {
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [errors, setErrors] = useState<Record<string, string>>({});

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    const newErrors: Record<string, string> = {};

    if (!email) newErrors.email = '이메일은 필수입니다';
    if (!password) newErrors.password = '비밀번호는 필수입니다';

    if (Object.keys(newErrors).length > 0) {
      setErrors(newErrors);
      return;
    }

    console.log('로그인:', { email, password });
    alert('로그인 되었습니다!');
  };

  return (
    <form onSubmit={handleSubmit} style={{ display: 'flex', flexDirection: 'column', gap: '1.5rem' }}>
      <Input
        label="이메일"
        type="email"
        value={email}
        onChange={setEmail}
        isInvalid={!!errors.email}
        errorMessage={errors.email}
        isRequired
      />

      <Input
        label="비밀번호"
        type="password"
        value={password}
        onChange={setPassword}
        isInvalid={!!errors.password}
        errorMessage={errors.password}
        isRequired
      />

      <Button variant="primary">로그인</Button>
    </form>
  );
}
```

### 2. 회원가입 폼

여러 인풋 필드를 관리하는 예제입니다:

```tsx
import { Input } from '@/components/ui/Input';
import { Button } from '@/components/ui/Button';
import { useState } from 'react';

export function SignUpFormExample() {
  const [formData, setFormData] = useState({
    name: '',
    email: '',
    password: '',
    confirmPassword: '',
  });

  const handleChange = (field: string, value: string) => {
    setFormData(prev => ({ ...prev, [field]: value }));
  };

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    if (formData.password !== formData.confirmPassword) {
      alert('비밀번호가 일치하지 않습니다');
      return;
    }
    console.log('가입:', formData);
    alert('가입 완료되었습니다!');
  };

  return (
    <form onSubmit={handleSubmit} style={{ display: 'flex', flexDirection: 'column', gap: '1.5rem' }}>
      <Input
        label="이름"
        type="text"
        value={formData.name}
        onChange={(v) => handleChange('name', v)}
        placeholder="전체 이름"
        isRequired
      />

      <Input
        label="이메일"
        type="email"
        value={formData.email}
        onChange={(v) => handleChange('email', v)}
        placeholder="email@example.com"
        isRequired
      />

      <Input
        label="비밀번호"
        type="password"
        value={formData.password}
        onChange={(v) => handleChange('password', v)}
        placeholder="최소 8자"
        isRequired
      />

      <Input
        label="비밀번호 확인"
        type="password"
        value={formData.confirmPassword}
        onChange={(v) => handleChange('confirmPassword', v)}
        placeholder="비밀번호 재입력"
        isRequired
      />

      <Button variant="primary">회원가입</Button>
    </form>
  );
}
```
