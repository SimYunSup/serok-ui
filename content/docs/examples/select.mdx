## 기본 사용법

Select 컴포넌트의 가장 간단한 사용 방법입니다.

```tsx
import { Select, Item } from '@/components/ui/Select';

export function BasicExample() {
  return (
    <Select label="과일을 선택하세요">
      <Item key="apple">사과</Item>
      <Item key="banana">바나나</Item>
      <Item key="orange">오렌지</Item>
    </Select>
  );
}
```

## 비제어 Select

자신의 상태를 스스로 관리하는 선택 상자입니다.

```tsx
import { Select, Item } from '@/components/ui/Select';

export function UncontrolledExample() {
  return (
    <Select label="기본 선택" defaultSelectedKey="option2">
      <Item key="option1">옵션 1</Item>
      <Item key="option2">옵션 2</Item>
      <Item key="option3">옵션 3</Item>
    </Select>
  );
}
```

## 제어 Select

부모 컴포넌트에 의해 상태가 관리되는 선택 상자입니다.

```tsx
import { Select, Item } from '@/components/ui/Select';
import { useState } from 'react';

export function ControlledExample() {
  const [selected, setSelected] = useState('option1');

  return (
    <Select
      label="옵션을 선택하세요"
      selectedKey={selected}
      onSelectionChange={setSelected}
    >
      <Item key="option1">옵션 1</Item>
      <Item key="option2">옵션 2</Item>
      <Item key="option3">옵션 3</Item>
    </Select>
  );
}
```

## 플레이스홀더 사용

플레이스홀더 텍스트가 있는 선택 상자입니다.

```tsx
import { Select, Item } from '@/components/ui/Select';

export function PlaceholderExample() {
  return (
    <Select label="국가" placeholder="국가를 선택하세요">
      <Item key="kr">대한민국</Item>
      <Item key="us">미국</Item>
      <Item key="jp">일본</Item>
      <Item key="cn">중국</Item>
    </Select>
  );
}
```

## 설명 포함

설명 및 유효성 검사 메시지가 있는 선택 상자입니다.

```tsx
import { Select, Item } from '@/components/ui/Select';
import { useState } from 'react';

export function DescriptionExample() {
  const [selected, setSelected] = useState('');
  const isInvalid = !selected;

  return (
    <Select
      label="옵션을 선택하세요"
      selectedKey={selected}
      onSelectionChange={setSelected}
      isRequired
      isInvalid={isInvalid}
      errorMessage={isInvalid ? '이 필드는 필수입니다' : ''}
      description="옵션을 선택해야 합니다"
    >
      <Item key="opt1">옵션 1</Item>
      <Item key="opt2">옵션 2</Item>
      <Item key="opt3">옵션 3</Item>
    </Select>
  );
}
```

## 비활성화된 옵션

비활성화된 옵션이 있는 선택 상자입니다.

```tsx
import { Select, Item } from '@/components/ui/Select';

export function DisabledOptionsExample() {
  return (
    <Select label="상태를 선택하세요">
      <Item key="active">활성</Item>
      <Item key="inactive" isDisabled>비활성</Item>
      <Item key="pending">대기 중</Item>
      <Item key="archived" isDisabled>보관됨</Item>
    </Select>
  );
}
```

## 비활성화된 Select

완전히 비활성화된 선택 상자입니다.

```tsx
import { Select, Item } from '@/components/ui/Select';

export function DisabledSelectExample() {
  return (
    <Select label="비활성화된 선택" isDisabled defaultSelectedKey="option1">
      <Item key="option1">옵션 1</Item>
      <Item key="option2">옵션 2</Item>
      <Item key="option3">옵션 3</Item>
    </Select>
  );
}
```
