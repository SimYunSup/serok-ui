## 기본 사용법

Button 컴포넌트의 가장 간단한 사용 방법입니다.

```tsx
import { Button } from '@/components/ui/Button';

export function BasicExample() {
  return <Button variant="primary">클릭하기</Button>;
}
```

## 모든 Variant

버튼은 4가지 시각적 변형을 지원합니다.

```tsx
import { Button } from '@/components/ui/Button';

export function VariantsExample() {
  return (
    <div style={{ display: 'flex', gap: '1rem', flexWrap: 'wrap' }}>
      <Button variant="primary">Primary</Button>
      <Button variant="secondary">Secondary</Button>
      <Button variant="accent">Accent</Button>
      <Button variant="negative">Negative</Button>
    </div>
  );
}
```

## 모든 크기

버튼의 4가지 크기를 보여줍니다.

```tsx
import { Button } from '@/components/ui/Button';

export function SizesExample() {
  return (
    <div style={{ display: 'flex', gap: '1rem', alignItems: 'center', flexWrap: 'wrap' }}>
      <Button variant="primary" size="s">작음</Button>
      <Button variant="primary" size="m">보통</Button>
      <Button variant="primary" size="l">큼</Button>
      <Button variant="primary" size="xl">매우 큼</Button>
    </div>
  );
}
```

## 이벤트 핸들러

버튼 클릭 이벤트와 상태 업데이트입니다.

```tsx
import { Button } from '@/components/ui/Button';
import { useState } from 'react';

export function InteractiveExample() {
  const [count, setCount] = useState(0);

  return (
    <Button variant="primary" onPress={() => setCount(c => c + 1)}>
      클릭됨 {count}회
    </Button>
  );
}
```

## 비활성화 상태

다양한 variant의 비활성화된 버튼 상태입니다.

```tsx
import { Button } from '@/components/ui/Button';

export function DisabledExample() {
  return (
    <div style={{ display: 'flex', gap: '1rem', flexWrap: 'wrap' }}>
      <Button variant="primary" isDisabled>비활성 Primary</Button>
      <Button variant="secondary" isDisabled>비활성 Secondary</Button>
      <Button variant="accent" isDisabled>비활성 Accent</Button>
      <Button variant="negative" isDisabled>비활성 Negative</Button>
    </div>
  );
}
```

## 로딩 상태

비동기 작업 중 보여지는 대기 상태입니다.

```tsx
import { Button } from '@/components/ui/Button';
import { useState } from 'react';

export function PendingExample() {
  const [isLoading, setIsLoading] = useState(false);

  const handleClick = async () => {
    setIsLoading(true);
    try {
      await new Promise(resolve => setTimeout(resolve, 2000));
    } finally {
      setIsLoading(false);
    }
  };

  return (
    <Button variant="primary" isPending={isLoading} onPress={handleClick}>
      {isLoading ? '로딩 중...' : '제출'}
    </Button>
  );
}
```
