# Toast

## Overview

Toast is a notification component that displays brief, non-intrusive messages to users. Toasts are used for operation feedback, error alerts, and informational notifications. Serok UI's Toast component extends React Spectrum's Toast with a simplified API using ToastQueue methods.

## Quick Start

First, add `ToastContainer` to your app's root:

```tsx
// app/root.tsx or top-level layout
import { ToastContainer } from '@/components/ui/Toast';
import { SerokProvider } from '@/components/ui/Provider';

export function Layout({ children }) {
  return (
    <SerokProvider>
      {children}
      <ToastContainer />
    </SerokProvider>
  );
}
```

Then use `ToastQueue` anywhere to show toasts:

```tsx
import { ToastQueue } from '@/utils/toast';
import { Button } from '@/components/ui/Button';

export function MyComponent() {
  return (
    <Button
      variant="primary"
      onPress={() => ToastQueue.positive('Saved successfully!')}
    >
      Save
    </Button>
  );
}
```

## Props

### ToastQueue Methods

| Method | Description | Icon |
|--------|-------------|------|
| `ToastQueue.neutral(message, options?)` | General notification (no icon) | — |
| `ToastQueue.info(message, options?)` | Informational notification | Blue info icon |
| `ToastQueue.positive(message, options?)` | Success notification | Green check icon |
| `ToastQueue.negative(message, options?)` | Error/warning notification | Red warning icon |

### Options

| Option | Type | Required | Default | Description |
|--------|------|----------|---------|-------------|
| `actionLabel` | `string` | No | — | Text for action button |
| `onAction` | `() => void` | No | — | Callback when action button clicked |
| `shouldCloseOnAction` | `boolean` | No | `false` | Auto-close toast on action click |
| `onClose` | `() => void` | No | — | Callback when toast closes |
| `timeout` | `number` | No | `5000` | Auto-dismiss time (ms, min 5000ms) |

**Additional Notes**:
- All methods return a `close()` function for programmatic dismissal
- Toasts with action buttons do not auto-dismiss
- Multiple toasts are managed in a queue

## Variants & States

### Semantic Variants

| Variant | Method | Use Case |
|---------|--------|----------|
| Neutral | `ToastQueue.neutral()` | General notifications, neutral info |
| Info | `ToastQueue.info()` | Informational alerts, tips, guidance |
| Positive | `ToastQueue.positive()` | Success feedback, completion messages |
| Negative | `ToastQueue.negative()` | Errors, warnings, failure notifications |

### Behavioral States

- **Visible**: Toast displayed on screen
- **With Action**: Contains action button, no auto-dismiss
- **Auto-dismiss**: Closes after timeout (default 5 seconds)

## Examples

### Basic Usage

Simplest way to show a toast notification.

```tsx
import { ToastQueue } from '@/utils/toast';
import { Button } from '@/components/ui/Button';

export function BasicExample() {
  return (
    <Button
      variant="primary"
      onPress={() => ToastQueue.neutral('Message here')}
    >
      Show Toast
    </Button>
  );
}
```

### With Action Button

Toast with an action button for user interaction.

```tsx
import { ToastQueue } from '@/utils/toast';
import { Button } from '@/components/ui/Button';

export function ActionExample() {
  return (
    <Button
      variant="primary"
      onPress={() => ToastQueue.info('Update available', {
        actionLabel: 'Update',
        onAction: () => console.log('Action clicked!'),
        shouldCloseOnAction: true,
      })}
    >
      Toast with Action
    </Button>
  );
}
```

### Programmatic Close

Manually closing a toast using the returned close function.

```tsx
import { ToastQueue } from '@/utils/toast';
import { Button } from '@/components/ui/Button';
import { useState } from 'react';

export function ProgrammaticCloseExample() {
  const [closeToast, setCloseToast] = useState<(() => void) | null>(null);

  const handlePress = () => {
    if (closeToast) {
      closeToast();
      setCloseToast(null);
    } else {
      const close = ToastQueue.info('This toast can be closed programmatically', {
        onClose: () => setCloseToast(null),
      });
      setCloseToast(() => close);
    }
  };

  return (
    <Button variant="primary" onPress={handlePress}>
      {closeToast ? 'Close Toast' : 'Show Toast'}
    </Button>
  );
}
```

### Async Operation Feedback

Showing success/error toasts after async operations.

```tsx
import { ToastQueue } from '@/utils/toast';
import { Button } from '@/components/ui/Button';
import { useState } from 'react';

export function AsyncExample() {
  const [isLoading, setIsLoading] = useState(false);

  const handleSave = async () => {
    setIsLoading(true);
    try {
      await new Promise(resolve => setTimeout(resolve, 1000));
      ToastQueue.positive('Changes saved successfully');
    } catch (error) {
      ToastQueue.negative('Failed to save. Please try again.');
    } finally {
      setIsLoading(false);
    }
  };

  return (
    <Button variant="primary" isPending={isLoading} onPress={handleSave}>
      Save
    </Button>
  );
}
```

### Undo Pattern

Toast with undo action for destructive operations.

```tsx
import { ToastQueue } from '@/utils/toast';
import { Button } from '@/components/ui/Button';

export function UndoExample() {
  const handleDelete = () => {
    console.log('Item deleted');

    ToastQueue.neutral('Item deleted', {
      actionLabel: 'Undo',
      onAction: () => {
        console.log('Delete undone');
        ToastQueue.positive('Deletion undone');
      },
      shouldCloseOnAction: true,
    });
  };

  return (
    <Button variant="negative" onPress={handleDelete}>
      Delete
    </Button>
  );
}
```
