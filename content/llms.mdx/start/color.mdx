# Serok UI Color System

Serok UI implements Adobe Spectrum's redesigned color system with 14 tints and shades per color (100-1400 scale), optimized for perceptual uniformity and accessibility.

## Color Scale Architecture

### Scale Ranges

| Range | Background Reference | Usage |
|-------|---------------------|-------|
| **100-500** | vs Black (#000) | Light colors for dark mode text, backgrounds |
| **600-1000** | vs White (#FFF) | Dark colors for light mode buttons, text |
| **1100-1400** | vs White (#FFF) | High contrast mode, AAA accessibility |

### Design Principles

The color system applies:

1. **Stevens' Power Law** - Polynomial curve for perceptually balanced lightness distribution
2. **CAM02-UCS** - Perceptually uniform color space
3. **Bezold-Brücke Shift** - Models how light intensity affects hue perception
4. **Simultaneous Brightness Contrast** - Theme-specific optimizations

## APCA Contrast Analysis

### About APCA

Advanced Perceptual Contrast Algorithm (APCA) is a next-generation contrast calculation method that more accurately reflects human visual perception compared to WCAG 2.x contrast ratios.

### Light Colors (100-500): Black Background Reference

Measures contrast against **#000000** for dark mode text readability:

| Step | APCA Lc vs Black | Recommended Use |
|------|------------------|-----------------|
| 100 | Lc 95-100 | Dark mode primary text |
| 200 | Lc 85-95 | Dark mode body text |
| 300 | Lc 75-85 | Dark mode secondary text |
| 400 | Lc 65-75 | Dark mode disabled text |
| 500 | Lc 50-65 | Dark mode hint text |

**Usage Example:**

```css
.dark-mode-text {
  background: var(--serok-gray-900);
  color: var(--serok-purple-200);
}

.dark-surface {
  background: var(--serok-gray-800);
  border: 1px solid var(--serok-purple-400);
}
```

### Dark Colors (600-1000): White Background Reference

Measures contrast against **#FFFFFF** for light mode button and text readability:

| Step | APCA Lc vs White | Recommended Use |
|------|------------------|-----------------|
| 600 | Lc 45-55 | Secondary icons, decorative |
| 700 | Lc 55-65 | **Primary action buttons** |
| 800 | Lc 65-75 | Hover state, emphasis text |
| 900 | Lc 75-85 | Active/Pressed state |
| 1000 | Lc 85-95 | Body text, strong emphasis |

**Usage Example:**

```css
.primary-button {
  background: var(--serok-purple-700);
  color: var(--serok-gray-0);
}

.primary-button:hover {
  background: var(--serok-purple-800);
}

.primary-button:active {
  background: var(--serok-purple-900);
}

.light-mode-text {
  background: var(--serok-gray-0);
  color: var(--serok-purple-900);
}
```

### High Contrast Colors (1100-1400)

For WCAG AAA compliance and high contrast accessibility mode:

| Step | APCA Lc vs White | Use |
|------|------------------|-----|
| 1100 | Lc 90+ | High contrast default |
| 1200 | Lc 93+ | High contrast hover |
| 1300 | Lc 95+ | High contrast active |
| 1400 | Lc 98+ | Maximum contrast |

**Usage Example:**

```css
@media (prefers-contrast: high) {
  .primary-button {
    background: var(--serok-purple-1100);
  }

  .primary-button:hover {
    background: var(--serok-purple-1200);
  }

  .primary-button:active {
    background: var(--serok-purple-1300);
  }
}

.high-contrast-text {
  color: var(--serok-purple-1400);
}
```

## Light Mode vs Dark Mode

Adobe Spectrum accounts for **Simultaneous Brightness Contrast** - the perceptual difference in how brightness is perceived across themes.

### Light Mode Color Selection

Text and icons become progressively **darker**:

```css
.text-default { color: var(--serok-gray-900); }
.text-secondary { color: var(--serok-gray-700); }
.text-tertiary { color: var(--serok-gray-600); }
```

### Dark Mode Color Selection

Text and icons become progressively **lighter**:

```css
.text-default { color: var(--serok-gray-100); }
.text-secondary { color: var(--serok-gray-300); }
.text-tertiary { color: var(--serok-gray-400); }
```

## Color Selection Guidelines

### Buttons and Actions

| State | Step | Example |
|-------|------|---------|
| Default | 700 | `--serok-purple-700` |
| Hover | 800 | `--serok-purple-800` |
| Active | 900 | `--serok-purple-900` |

### Backgrounds and Surfaces

| Usage | Step | Example |

| Card surface | 50-100 | `--serok-gray-50` |
| Accent surface | 100-200 | `--serok-purple-100` |

|------------|------|

| Emphasis border | 400-500 |

```css
--spectrum-negative-color-*
```

2. **Serok Provider Colors** (Second choice)

```css

```

3. **Never Hardcode**

```css
color: #6c757d;  /* ❌ Don't do this */
```

## Accessibility Compliance

### WCAG 2.1 AA Requirements

- **Text**: Minimum 4.5:1 contrast (14px+)
- **Large text**: Minimum 3:1 contrast (18px+ or 14px bold)
- **UI components**: Minimum 3:1 contrast

### APCA Recommendations

| Usage | Minimum APCA |
|-------|-------------|
| Body text | Lc 60+ |
| Large text/headings | Lc 45+ |
| Icons | Lc 45+ |
| Decorative elements | Lc 30+ |

```tsx

    <SerokProvider colorScheme="light">
```
