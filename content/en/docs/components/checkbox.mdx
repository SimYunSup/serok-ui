# Checkbox

## Overview

A checkbox is a form control that allows users to select or deselect a single option. Checkboxes are commonly used for binary choices, form field validation, and "select all" patterns. Serok UI's Checkbox component extends React Spectrum's Checkbox with custom variants and styling to match the Serok design system.

## Quick Start

Minimal working example showing the most common usage pattern:

```tsx
import { Checkbox } from '@/components/ui/Checkbox';

export function MyComponent() {
  return <Checkbox variant="default">Accept terms</Checkbox>;
}
```

## Props

| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| `variant` | `"default" \| "accent" \| "secondary"` | No | `"default"` | Visual style variant |
| `isSelected` | `boolean` | No | — | Controlled selected state |
| `defaultSelected` | `boolean` | No | `false` | Uncontrolled initial selected state |
| `onChange` | `(isSelected: boolean) => void` | No | — | Called when selection state changes |
| `isIndeterminate` | `boolean` | No | `false` | Indeterminate state (for "select all" patterns) |
| `isDisabled` | `boolean` | No | `false` | Disable user interaction |
| `isReadOnly` | `boolean` | No | `false` | Read-only mode, no interaction possible |
| `isRequired` | `boolean` | No | `false` | Mark as required field |
| `isInvalid` | `boolean` | No | `false` | Validation failure state |
| `children` | `ReactNode` | Yes | — | Checkbox label text or content |
| `value` | `string` | No | — | Form submission value |

**Additional Notes**:
- All props follow React Spectrum naming conventions
- Props are case-sensitive
- Default values are shown exactly as they appear in code
- Extends all props from React Spectrum's `@react-spectrum/checkbox` component

## Variants & States

### Visual Variants

| Variant | Props | Use Case |
|---------|-------|----------|
| Default | `variant="default"` | Standard checkboxes, neutral styling |
| Accent | `variant="accent"` | Important selections, emphasized checkboxes |
| Secondary | `variant="secondary"` | Less important selections, secondary choices |

### Behavioral States

- **Unchecked**: Not selected, empty checkbox
- **Checked** (`isSelected={true}`): Selected, checkmark visible
- **Indeterminate** (`isIndeterminate={true}`): Mixed state, for parent selections
- **Disabled** (`isDisabled={true}`): No interaction, grayed out
- **Read-only** (`isReadOnly={true}`): Shows state but no interaction possible
- **Invalid** (`isInvalid={true}`): Validation error state

## Examples

### Basic Usage

Simplest way to use the Checkbox component with default variant.

```tsx
import { Checkbox } from '@/components/ui/Checkbox';

export function BasicExample() {
  return <Checkbox variant="default">Accept terms</Checkbox>;
}
```

### Uncontrolled Checkbox

Checkbox managing its own state with default initial value.

```tsx
import { Checkbox } from '@/components/ui/Checkbox';

export function UncontrolledExample() {
  return (
    <Checkbox variant="default" defaultSelected={false}>
      Subscribe to newsletter
    </Checkbox>
  );
}
```

### Controlled Checkbox

Checkbox with state managed by parent component.

```tsx
import { Checkbox } from '@/components/ui/Checkbox';
import { useState } from 'react';

export function ControlledExample() {
  const [isSelected, setIsSelected] = useState(false);

  return (
    <Checkbox
      variant="default"
      isSelected={isSelected}
      onChange={setIsSelected}
    >
      I agree to the terms
    </Checkbox>
  );
}
```

### Indeterminate State

Example showing indeterminate state for "select all" patterns.

```tsx
import { Checkbox } from '@/components/ui/Checkbox';
import { useState } from 'react';

export function IndeterminateExample() {
  const [items, setItems] = useState({
    item1: false,
    item2: true,
    item3: false,
  });

  const allSelected = Object.values(items).every(Boolean);
  const someSelected = Object.values(items).some(Boolean);

  const handleSelectAll = (isSelected: boolean) => {
    const newItems: typeof items = {};
    Object.keys(items).forEach(key => {
      newItems[key as keyof typeof items] = isSelected;
    });
    setItems(newItems);
  };

  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: '1rem' }}>
      <Checkbox
        variant="default"
        isSelected={allSelected}
        isIndeterminate={someSelected && !allSelected}
        onChange={handleSelectAll}
      >
        Select All Items
      </Checkbox>
      {Object.entries(items).map(([key, value]) => (
        <Checkbox
          key={key}
          variant="default"
          isSelected={value}
          onChange={(checked) => setItems({ ...items, [key]: checked })}
        >
          {key}
        </Checkbox>
      ))}
    </div>
  );
}
```
