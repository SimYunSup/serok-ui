## Version Management

### About Versioning

Since Serok UI uses the **shadcn/ui copy-paste distribution model**:

- **No semantic versioning** - Components are copied into your project
- **Full ownership** - You control when and how to update
- **No breaking changes from upgrades** - Components in your codebase don't change unless you explicitly modify them
- **Optional updates** - Decide independently whether to adopt new component versions

To use newer component versions:
1. Check [serok.ethansup.net](https://serok.ethansup.net) for latest designs
2. Update the component file in your project manually
3. Test and verify the changes work for your use case

## Key Takeaways

1. **Foundation**: Serok UI is built on React Spectrum - a proven, accessible design system
2. **Flexibility**: Copy-paste components mean full control and no lock-in
3. **Community**: Participate in improving the project through issues and discussions
4. **Learning**: Use this as an opportunity to understand React, TypeScript, and accessibility
5. **Standards**: Follow WCAG 2.1 AA guidelines for accessible components
